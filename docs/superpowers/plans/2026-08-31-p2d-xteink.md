# P2d 上传（xteink）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 实现 `xteink.py`：`XteinkClient.push_file(path, filename) -> record_id`，完成「登录取 token（缓存到 `State.kv`）→ 申请 OSS 签名 → 上传到阿里云 OSS → 回调确认」四步，401 自动重登重试。

**Architecture:** 一个 `XteinkClient` 类，构造时吃 `XteinkConfig` + `State`（用于 token 缓存）。协议已通过抓包完全确认（spec 第 7 节）。所有 api-prod 请求带 `Authorization: Bearer`；OSS 那步用 multipart 表单、不带 auth、不走代理。HTTP 用 httpx，`respx` mock 测试。

**Tech Stack:** Python 3.12、httpx、pytest、respx。

**Spec:** `docs/superpowers/specs/2026-08-31-push2xteink-design.md` 第 7 节（**这是本计划的权威协议来源，逐字对照**）+ 第 13 节。

## Global Constraints

- Python `>=3.12`；`X | None` / `list[...]` 标注。
- HTTP 用 `httpx`，显式 `timeout=`（默认 30s）。**xteink 上传全程不走代理**（spec 第 7 节）。
- `XteinkConfig` 来自 `push2xteink.models`（P1，**不可改**）：`XteinkConfig(username: str, password: str, api_base: str = "https://api-prod.xteink.cn")`。
- `State` 来自 P1：`State.kv_get(key) -> str | None`、`State.kv_set(key, value)`。token 缓存用 key `xteink_access_token` 和 `xteink_token_obtained_at`（后者存 `time.time()` 的字符串）。
- token 过期判定：无缓存，或 `now - obtained_at > 25 天`（access_token 实测有效期 ~29 天，留 4 天余量；不依赖登录响应的 `expires_in`，用固定 25 天简化）。
- 所有 datetime/时间戳这里用 `time.time()` float（epoch 秒），不涉及 tz。
- content_type 由扩展名映射：`.epub → application/epub+zip`、`.txt → text/plain`；其它扩展名 → `raise XteinkUploadError`。
- 测试不发真实网络请求（respx mock）；不打真实 xteink 接口。
- 源文件 `src/push2xteink/`，测试 `tests/`。

```python
from __future__ import annotations

import hashlib
import time
from pathlib import Path

import httpx

from .models import XteinkConfig
from .state import State

_UA = {"User-Agent": "push2xteink/0.1"}
_CONTENT_TYPES = {".epub": "application/epub+zip", ".txt": "text/plain"}
_TOKEN_KEY = "xteink_access_token"
_TOKEN_TS_KEY = "xteink_token_obtained_at"
_TOKEN_MAX_AGE = 25 * 24 * 3600


class XteinkUploadError(Exception):
    """xteink 上传流程任一步失败。"""


class XteinkClient:
    def __init__(self, config: XteinkConfig, state: State, *, timeout: float = 30.0) -> None:
        self._cfg = config
        self._state = state
        self._timeout = timeout
        self._api = config.api_base.rstrip("/")

    # --- token ---
    def _login(self) -> str:
        try:
            with httpx.Client(timeout=self._timeout, headers=_UA) as client:
                resp = client.post(
                    f"{self._api}/auth/login",
                    json={"username": self._cfg.username, "password": self._cfg.password},
                )
                resp.raise_for_status()
                data = resp.json()
        except httpx.HTTPError as exc:
            raise XteinkUploadError(f"login request failed: {exc}") from exc
        token = data.get("access_token")
        if not token:
            raise XteinkUploadError(f"login response had no access_token: {data!r}")
        return token

    def _access_token(self, *, force_refresh: bool = False) -> str:
        if not force_refresh:
            cached = self._state.kv_get(_TOKEN_KEY)
            ts = float(self._state.kv_get(_TOKEN_TS_KEY) or 0.0)
            if cached and (time.time() - ts) <= _TOKEN_MAX_AGE:
                return cached
        token = self._login()
        self._state.kv_set(_TOKEN_KEY, token)
        self._state.kv_set(_TOKEN_TS_KEY, str(time.time()))
        return token
```

```
C. POST {api_base}/api/v1/upload/callback
   headers: Authorization: Bearer {token}

```

```python
    def _request_signature(
        self, token: str, filename: str, content_type: str, file_md5: str, file_size: int
    ) -> dict:
        try:
            with httpx.Client(timeout=self._timeout, headers=_UA) as client:
                resp = client.post(
                    f"{self._api}/api/v1/upload/signature",
                    headers={"Authorization": f"Bearer {token}"},
                    json={
                        "filename": filename,
                        "content_type": content_type,
                        "file_md5": file_md5,
                        "file_size": file_size,
                        "prefix": "uploads/book",
                    },
                )
                resp.raise_for_status()
                return resp.json()
        except httpx.HTTPError as exc:
            raise XteinkUploadError(f"signature request failed: {exc}") from exc

    def _upload_to_oss(self, sig: dict, content_type: str, data: bytes) -> None:
        files = {
            "key": (None, sig["key"]),
            "policy": (None, sig["policy"]),
            "OSSAccessKeyId": (None, sig["access_key_id"]),
            "signature": (None, sig["signature"]),
            "Content-Type": (None, content_type),
            "file": ("file", data, content_type),
        }
        try:
            with httpx.Client(timeout=self._timeout, headers=_UA) as client:
                resp = client.post(sig["host"], files=files)
        except httpx.HTTPError as exc:
            raise XteinkUploadError(f"OSS upload failed: {exc}") from exc
        if resp.status_code != 204:
            raise XteinkUploadError(
                f"OSS upload returned {resp.status_code}: {resp.text[:200]}"
            )

    def _callback(
        self, token: str, sig: dict, filename: str, file_md5: str,
        file_size: int, content_type: str,
    ) -> str:
        try:
            with httpx.Client(timeout=self._timeout, headers=_UA) as client:
                resp = client.post(
                    f"{self._api}/api/v1/upload/callback",
                    headers={"Authorization": f"Bearer {token}"},
                    json={
                        "oss_key": sig["key"],
                        "filename": filename,
                        "file_size": file_size,
                        "file_md5": file_md5,
                        "content_type": content_type,
                    },
                )
                resp.raise_for_status()
                data = resp.json()
        except httpx.HTTPError as exc:
            raise XteinkUploadError(f"callback request failed: {exc}") from exc
        record_id = data.get("record_id")
        if not record_id:
            raise XteinkUploadError(f"callback response had no record_id: {data!r}")
        return record_id
```

## Task 3: `push_file` 编排 + 401 重登重试

**Files:**
- Modify: `src/push2xteink/xteink.py`
- Modify: `tests/test_xteink.py`

**Interfaces:**
- Produces: `XteinkClient.push_file(path: Path, filename: str) -> str`

**行为**：
1. `ext = path.suffix.lower()`；`content_type = _CONTENT_TYPES.get(ext)`；`None` → `XteinkUploadError`。
2. `data = path.read_bytes()`；`file_md5 = hashlib.md5(data).hexdigest()`；`file_size = len(data)`。
3. `token = self._access_token()`。
4. `sig = self._request_signature(token, filename, content_type, file_md5, file_size)`。
   - **若 `_request_signature` 抛出且 HTTP 状态是 401** → `token = self._access_token(force_refresh=True)`，重试一次 signature。（实现：让 `_request_signature` / `_callback` 在 401 时抛一个带标记的 `XteinkUploadError`，或单独一个 `_XteinkAuthError(XteinkUploadError)` 子类；`push_file` 捕获它做一次重登重试。）
5. `if not sig.get("instant_upload"): self._upload_to_oss(sig, content_type, data)`。
6. `record_id = self._callback(token, sig, filename, file_md5, file_size, content_type)`（callback 也做同样的 401 重登重试一次）。
7. 返回 `record_id`。

实现要点：把 signature/callback 里的 `resp.raise_for_status()` 换成显式判断——`if resp.status_code == 401: raise _XteinkAuthError(...)`，其余非 2xx `raise XteinkUploadError(...)`。`push_file` 用一个小 helper `self._auth_retry(fn)` 跑「fn(token) → 若 `_XteinkAuthError` → force_refresh → fn(new_token) 一次 → 再失败原样抛」。

```python
    def push_file(self, path: Path, filename: str) -> str:

        content_type = _CONTENT_TYPES.get(ext)

            raise XteinkUploadError(f"unsupported file extension {ext!r} (no content type)")

        file_md5 = hashlib.md5(data).hexdigest()
        file_size = len(data)

            lambda tok: self._request_signature(tok, filename, content_type, file_md5, file_size)

        if not sig.get("instant_upload"):
```
